POS-Ordering-System

The project is a simple Python-based Point-ofSale (POS) Ordering System designed
for a small store.It allows users to view available products, select items, enter quantities, and calculate
the total cost of their orders.The project also demonstrates teamwork andcollaboration using Git, GitHub, and VS Code.
